## 1. Cari Tahu Nama Disk

Pertama, cek dulu disk mana yang punya _unallocated space_ atau ruang kosong itu

```bash
lsblk
```

_(Misal nama disknya `/dev/nvme1n1p1`)_

---

### 2. Buat Partisi Baru dengan `cfdisk`

Jalankan `cfdisk` pada disk tersebut:

```bash
sudo cfdisk /dev/nvme1n1
```

_(Ganti `/dev/nvme1n1` dengan nama disk kamu)_.

**Di dalam menu `cfdisk`:**

1. Gunakan panah atas/bawah untuk pilih bagian yang tulisannya Free Space.
    
2. Pilih [ New ] di menu bawah, terus tekan `Enter`.
    
3. Masukin ukuran yang kamu mau (misal `50G` atau langsung `Enter` kalau mau habisin sisa _space_).
    
4. Pilih tipe partisinya (defaultnya adalah Linux filesystem, jadi biasanya nggak perlu diubah).
    
5. Pilih [ Write ], lalu ketik `yes` untuk menyimpan perubahan ke disk.
    
6. Pilih [ Quit ].
    

---

### 3. Format Jadi Linux Filesystem (ext4)

Setelah partisinya dibuat (misal namanya jadi `/dev/nvme0n1p6`), kita format ke ext4 (atau apapun FS mu) agar bisa dipakai menyimpan file.

```bash
sudo mkfs.ext4 /dev/nvme1n1p6
```

_(Ganti `p6` dengan nomor partisi baru yang baru saja muncul di `lsblk`)_.

---

### 4. Cek Hasilnya

Cek lagi dengan `lsblk`. Sekarang partisi tersebut harusnya sudah punya nama dan siap di-_mount_.

```bash
lsblk -f
```

---
### 5.  Identifikasi dan Persiapan Pemindahan

- **Cek UUID partisi baru:**
    
    ```bash
    blkid
    ```
    
    _(Cari partisi besar yang ingin dijadikan `/home`, catat UUID-nya)_.
    
- **Backup folder home lama:**
    
    ```bash
    sudo mv /home /home_backup
    ```
    
    _(Ini memindahkan folder `/home` asli di partisi 70GB menjadi `/home_backup` sebagai cadangan)_.
    
- **Buat mount point baru:**
    
    ```bash
    sudo mkdir /home
    ```
    
    _(Folder kosong ini akan menjadi tempat menempelnya partisi baru nanti)_.
    

---

### 6. Migrasi Data (Rsync)

Proses memindahkan data dari backup ke partisi baru dengan menjaga izin file (_permissions_).

- **Mount partisi baru ke folder sementara:**
    
    ```bash
    sudo mount /dev/nvme1n1p6 /mnt
    ```
    
    _(Ganti `/dev/nvme1n1p6` dengan partisi barumu)_.
    
- **Salin data:**
    
    ```bash
    sudo rsync -aAXv /home_backup/ /mnt/
    ```
    
    _(Flag `-aAX` memastikan semua atribut file, termasuk config Hyprland, tersalin sempurna)_.
    
- **Lepas mount sementara:**
    
    ```bash
    sudo umount /mnt
    ```
    

---

### 7. Konfigurasi Sistem (`/etc/fstab`)

Langkah ini agar partisi tersebut otomatis terpasang saat laptop dinyalakan.

- **Edit file fstab:**
    
    ```bash
    sudo vim /etc/fstab
    ```
    
- **Tambahkan/Edit baris `/home` dengan opsi "Sabar" (Timeout):**
    
    ```
    UUID=<uuid-partisi-baru>  /home  ext4  defaults,nofail,x-systemd.device-timeout=10s  0  2
    ```
    
    _(Ganti `<uuid-partisi-baru>` dengan hasil dari `blkid` tadi)_.

### 8. Perbaikan Booting (Solusi Agar Tidak _Stuck_)

Akhirnya edit sddm nya lol
`sudo systemctl edit sddm.service`

Terus minta dia sleep 2s, nunggu semua filesystem ke load.

```bash
### Editing /etc/systemd/system/sddm.service.d/override.conf
### Anything between here and the comment below will become the contents of the drop-in file

[Service]
ExecStartPre=/usr/bin/sleep 2

### Edits below this comment will be discarded


### /usr/lib/systemd/system/sddm.service
# [Unit]
# Description=Simple Desktop Display Manager
# Documentation=man:sddm(1) man:sddm.conf(5)
# Conflicts=getty@tty1.service
# After=systemd-user-sessions.service getty@tty1.service plymouth-quit.service systemd-logind.service
# PartOf=graphical.target
# StartLimitIntervalSec=30
# StartLimitBurst=2
#
# [Service]
# ExecStart=/usr/bin/sddm
# Restart=always
#
# [Install]
# Alias=display-manager.service
```

Terus bisa, yey

### 9. Optimasi Ruang (Docker & Cleanup)

Gue juga mindahin data docker biar kaga berat

- **Pindahkan Docker ke partisi baru:**
    
    1. `sudo systemctl stop docker.socket docker`
        
    2. `sudo mkdir -p /home/docker-data`
        
    3. `sudo rsync -aAXv /var/lib/docker/ /home/docker-data/`
        
    4. Edit `/etc/docker/daemon.json` dan isi:
        
        ```json
        {
          "data-root": "/home/docker-data"
        }
        ```
        
    5. `sudo systemctl start docker`
        
- **Hapus folder backup (Jika sudah yakin 100% aman):**
    
    ```bash
    sudo rm -rf /home_backup
    ```
