**yak beberapa hari ini gue nyari cara buat enable secure boot di Arch**

Kenapa tiba-tiba termotivasi? Jujur, gara-gara kemaren ketambahan space, mau main valo sama TFT, tapi perlu secure boot (fk u vanguard)

Anw step-by-stepnya:

## Prerequisites

Sebelum mulai, pastiin:

- Dual boot Arch + Windows (UEFI mode)
- GRUB sebagai bootloader
- Secure Boot **disabled** dulu di BIOS (nanti enable setelah setup selesai)

## 1. Install sbctl

```bash
sudo pacman -S sbctl
```

sbctl ini tool buat manage secure boot keys di Arch. Lebih gampang daripada manual sign pake sbsigntools.

## 2. Check Status Secure Boot

```bash
sbctl status
```

Harusnya muncul:

- Setup Mode: Enabled
- Secure Boot: Disabled

Kalau Setup Mode masih Disabled, masuk BIOS terus **clear/delete all secure boot keys** dulu.

Di lenovo gue, opsi biosnya "Clear...". Nah itu dipencet aja.

## 3. Create dan Enroll Custom Keys

```bash
sudo sbctl create-keys
sudo sbctl enroll-keys -m
```

Flag `-m` itu penting banget buat dual boot! Ini bakal:

- Enroll custom keys
- **Tetep keep Microsoft keys** (buat Windows bisa boot)

Tanpa `-m`, Windows ga bakal bisa boot karena keys Microsoft ilang.

## 4. Sign Kernel dan GRUB

```bash
sudo sbctl sign -s /boot/vmlinuz-linux
sudo sbctl sign -s /boot/efi/EFI/arch/grubx64.efi
```

Ini bakal sign kernel sama GRUB pake custom keys yang udah dibuat tadi.

> Setelah ini sebenernya bisa coba enable aja Secure Boot-nya. Tapi, biasanya orang error habis ini. Cek aja langkah selanjutnya :)

## 5. Install GRUB dengan Embedded Modules + SBAT

Ini **step paling krusial**. GRUB perlu semua module di-embed ke dalam binary karena sejak GRUB 2.06.r261, loading module lewat `insmod` di secure boot mode udah ga boleh.

Edit `/etc/default/grub`, tambahin:

```bash
GRUB_DISABLE_SHIM_LOCK=y
```

Terus install GRUB:

**SYNTAX FISH:**
> Jangan asal copas! Sesuain **`efi-directory`-nya dan `bootloader-id`-nya**!!!
```bash
set GRUB_MODULES "all_video boot btrfs cat chain configfile echo efifwsetup efinet ext2 fat font gettext gfxmenu gfxterm gfxterm_background gzio halt hfsplus iso9660 jpeg keystatus loadenv loopback linux ls lsefi lsefimmap lsefisystab memdisk minicmd normal ntfs part_apple part_msdos part_gpt password_pbkdf2 png probe reboot regexp search search_fs_uuid search_fs_file search_label sleep test true video xfs zfs zfscrypt zfsinfo tpm"

sudo grub-install --target=x86_64-efi --efi-directory=/boot/efi --bootloader-id=arch --modules="$GRUB_MODULES" --sbat /usr/share/grub/sbat.csv --disable-shim-lock
```

*Syntax Bash biasa:* Ganti `set GRUB_MODULES`  jadi  `GRUB_MODULES = `

> Kenapa perlu gini? Kita mastiin semua yang diperluin grub itu jadi satu, alias semuanya akan di load dari iso nya grub. Ini biar kita ga perlu sign satu-satu lagi modul Grub yang banyak itu.

Terus kalau udah install ulang grub, generate config:

```bash
sudo grub-mkconfig -o /boot/grub/grub.cfg
```

## 6. Sign GRUB Lagi + Setup Fallback Path

```bash
sudo sbctl sign -s /boot/efi/EFI/arch/grubx64.efi
sudo mkdir -p /boot/efi/EFI/Boot
sudo cp /boot/efi/EFI/arch/grubx64.efi /boot/efi/EFI/Boot/bootx64.efi
sudo sbctl sign -s /boot/efi/EFI/Boot/bootx64.efi
```

Fallback path ini penting kalau boot entry hilang atau firmware ga nemu bootloader utama.

## 7. Verify Semua File Udah Signed

```bash
sudo sbctl verify
```

Harusnya semua file ada checkmark ✓:

- `/boot/vmlinuz-linux` ✓
- `/boot/efi/EFI/arch/grubx64.efi` ✓
- `/boot/efi/EFI/Boot/bootx64.efi` ✓

## 8. Enable Secure Boot di BIOS

Reboot, masuk BIOS/UEFI settings, terus **enable Secure Boot**.

Boot lagi, cek status:

```bash
sudo sbctl status
```

Harusnya:

- Setup Mode: ✓ Disabled
- Secure Boot: ✓ Enabled
- Vendor Keys: microsoft

Kalau semua ✓, berarti **SUKSES**! Dual boot Arch + Windows jalan dengan secure boot enabled.

## 9. Setup Pacman Hooks (Auto-Sign saat Update)

Biar ga ribet manual sign setiap kali ada update kernel/GRUB:

**Hook untuk Kernel:**

```bash
sudo mkdir -p /etc/pacman.d/hooks
sudo nano /etc/pacman.d/hooks/99-secureboot.hook
```

Isi:

```ini
[Trigger]
Operation = Install
Operation = Upgrade
Type = Package
Target = linux
Target = linux-lts
Target = linux-zen
Target = linux-hardened

[Action]
Description = Signing kernel for Secure Boot
When = PostTransaction
Exec = /usr/bin/sh -c 'for kernel in /boot/vmlinuz-*; do /usr/bin/sbctl sign -s "$kernel"; done'
Depends = sbctl
```

**Hook untuk GRUB:**

```bash
sudo nano /etc/pacman.d/hooks/98-grub-secureboot.hook
```

Isi:

```ini
[Trigger]
Operation = Install
Operation = Upgrade
Type = Package
Target = grub

[Action]
Description = Signing GRUB for Secure Boot
When = PostTransaction
Exec = /usr/bin/sh -c '/usr/bin/sbctl sign -s /boot/efi/EFI/arch/grubx64.efi && /usr/bin/cp /boot/efi/EFI/arch/grubx64.efi /boot/efi/EFI/Boot/bootx64.efi && /usr/bin/sbctl sign -s /boot/efi/EFI/Boot/bootx64.efi'
Depends = sbctl
```

## 10. Nyalain Lagi Secure Boot

Ke Bios, dan enable aja lagi Secure Boot.

## 11. Test di Windows

Boot ke Windows, buka PowerShell as Admin:

```powershell
Confirm-SecureBootUEFI
```

Kalau return **True** → secure boot aktif, Vanguard siap jalan.

## Done!

Sekarang sistem full secure boot compliant. Arch tetep jalan, Windows jalan, Vanguard ga ngamuk lagi. GG!

---

**Troubleshooting:**

**Error "shim protocols not found":**

- Pastiin `GRUB_DISABLE_SHIM_LOCK=y` di `/etc/default/grub`
- Pastiin pake flag `--disable-shim-lock` waktu grub-install
- Pastiin SBAT file included (`--sbat /usr/share/grub/sbat.csv`)

**GRUB font jelek/rescue mode:**

- Berarti module belum di-embed. Ulangi step 5 dengan semua module dalam `GRUB_MODULES`

**Windows ga bisa boot:**

- Cek apakah enroll keys pake flag `-m` (buat keep Microsoft keys)
- Kalau lupa, ulangi: `sudo sbctl enroll-keys -m`
